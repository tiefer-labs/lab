# Start here

Status: in use. Owner: Tiefer. Licence: MPL 2.0.

For anyone who opens Tiefer Lab with a task in mind. This document owns the route from a task to the one document that answers it; it answers nothing itself. The list of every document is in [INDEX.md](INDEX.md).
